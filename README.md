# Arcade App 


Aplicación móvil desarrollada con React Native y Expo.

## Dominio

Sala de videojuegos / Arcade.

## Funcionalidades

- Lista de máquinas arcade
- Búsqueda en tiempo real
- Estado vacío personalizado
- Diseño reutilizable usando theme

## Tecnologías

- React Native
- Expo
- TypeScript
- pnpm
